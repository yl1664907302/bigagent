#### 可选：可执行的 YAML 决策模板（如需被 Agent 加载）
```yaml
version: 1
id: example-decision
name: 示例决策
description: 示例：按操作系统与环境标识调整采集频率
match:
  os: [windows, linux]
  arch: [amd64, arm64]
inputs:
  - type: osquery
    name: os_info
    query: select name, version from os_version
  - type: env
    name: hostname
    key: HOSTNAME
logic:
  if:
    any:
      - fact: os_info.name
        equals: Microsoft Windows 10 Pro
      - fact: hostname
        matches: ^prod-
  then:
    actions:
      - type: set_config
        key: system.sampling
        value: low
  else:
    actions:
      - type: set_config
        key: system.sampling
        value: high
```
