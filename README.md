# agent

## <font style="color:rgb(31, 35, 40);">BUILD</font>
```shell
go env -w GOOS=linux
go build -o "bigagent"
```

```powershell
go env -w GOOS=windows
go build -o "bigagent"
```

## <font style="color:rgb(31, 35, 40);">RUN</font>
```shell
./bigagent -s start 
```

```shell
./bigagent -s stop
```

```shell
./bigagent -s restart
```
