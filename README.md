## Build
```shell
go env -w GOOS=linux
go build -o "bigagent"
```

```powershell
go env -w GOOS=windows
go build -o "bigagent"
```

## Run
```shell
./bigagent -s start 
```

```shell
./bigagent -s stop
```

```shell
./bigagent -s restart
```
